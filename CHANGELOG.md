# Changelog

## 1.0.0 (2026-11-24)

- Standalone Checkmk 2.4/2.5 Veeam B&R REST monitoring integration.
- Veeam jobs and selected CustomPlatform sessions (HPE Morpheus and Kasten).
- Default job-focused discovery, optional VM/object-level checks.
- Per-job backup-age policies: off, daily, weekly, monthly, custom.
- No false daily-age alerts for weekly or monthly jobs by default.
- Repository availability and free-capacity monitoring.
- Mandatory endpoint and licensing failure reporting.
